# Presentation and launch video kit

Everything a person (or Claude Cowork) needs to build a sales or launch presentation and a short launch video for Cadence Lanes. It describes what the product does today; it does not invent customers, prices or results. Fill the gaps listed in [open-questions.md](open-questions.md) before publishing.

## Files

| File | Use it for |
|---|---|
| [product-brief.md](product-brief.md) | Who it is for, the problem, what the product does, what it does not do, proof points |
| [brand-and-style.md](brand-and-style.md) | Name, tagline, colours, fonts, tone of voice, do and do not |
| [copy-bank.md](copy-bank.md) | Taglines, headlines, one-liners, feature blurbs, calls to action |
| [deck-outline.md](deck-outline.md) | Slide-by-slide outline for a 10 to 12 slide deck |
| [video-script.md](video-script.md) | 45 to 60 second launch video: storyboard, voice-over, on-screen text, music notes |
| [demo-walkthrough.md](demo-walkthrough.md) | The demo school, logins, and a click path for screen recordings |
| [open-questions.md](open-questions.md) | Facts only the owner knows (pricing, contact, launch date, logos) |
| [screenshots/](screenshots/) | Real phone screens of the app (see list below) |

## How to brief Cowork

1. Give it this whole folder.
2. Ask for the deck first, using [deck-outline.md](deck-outline.md), [brand-and-style.md](brand-and-style.md) and [copy-bank.md](copy-bank.md).
3. Then ask for the video, using [video-script.md](video-script.md) and the same brand files.
4. Tell it to use only the facts in [product-brief.md](product-brief.md), and to leave a clearly marked placeholder for anything listed in [open-questions.md](open-questions.md).
